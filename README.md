# Super Goal 3 — Interactive Book

The releases of the Super Goal 3 interactive book for the classroom board: the Student Book and the Workbook, first semester.

Download the latest from **Releases** — `Super-Goal-3-Setup-<version>.exe` — and open it. No administrator is needed. The book updates itself from inside, and a teacher's classes and writing stay as they are.
